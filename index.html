1. เพิ่มหนังสืออ้างอิง

เลือกไฟล์ PDF จากแอป Files บน iPad ไฟล์จะถูกอ่านในเบราว์เซอร์นี้โดยตรง ไม่มีการอัปโหลดหนังสือไปยังเซิร์ฟเวอร์

ยังไม่ได้เลือกหนังสือ

2. สารบัญ / Bookmarks

สารบัญจาก PDF จะแสดงที่นี่ หากหนังสือมีข้อมูล Bookmarks

3. ค้นหาข้อมูลในหนังสือ

ค้นหาข้อความในทุกหน้า แตะผลลัพธ์เพื่อเปิดหน้าที่พบ

ผลการค้นหาจะแสดงที่นี่

4. ข้อมูลอ้างอิงสำหรับ AI DM

ส่วนนี้เป็นโครงสร้างเริ่มต้นสำหรับเก็บรายการอ้างอิงด้วยตนเองในเบราว์เซอร์ ยังไม่ได้เชื่อม AI หรือฐานข้อมูลถาวร

ยังไม่มีรายการอ้างอิง

5. อ่านหน้าหนังสือ

หน้า 0 / 0
เมื่อเลือกหนังสือแล้ว สามารถเปิดดูแต่ละหน้าได้

ลิงก์ภายใน PDF จะแสดงกรอบสีฟ้าเมื่อแตะ/ชี้ และกดเพื่อกระโดดไปยังหน้าเป้าหมายได้ ลิงก์เว็บไซต์ภายนอกจะเปิดแท็บใหม่

ขอบเขต V2

V2 เพิ่มชั้นลิงก์ Annotation สำหรับลิงก์ภายในและภายนอก PDF, สารบัญ Bookmarks และรายการอ้างอิงหัวข้อ/เลขหน้าแบบ local ในหน้าเว็บ
  • ยังค้นหาได้เฉพาะ PDF ที่มีข้อความฝังอยู่ หากเป็นภาพสแกนต้องเพิ่ม OCR
  • รายการอ้างอิงที่บันทึกใน V2 เก็บไว้ในหน่วยความจำของหน้าเว็บเท่านั้น รีเฟรชแล้วหาย
  • ยังไม่ได้เชื่อมโมเดล AI, การตัดสินกฎ, แคมเปญ หรือตัวละคร
  • ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด PDF.js จาก CDN
